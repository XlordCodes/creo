# Creo — Bug Tracker

Use this file to log any issues found during the manual QA pass of the 7 user journeys.

## Instructions

1. Assign a unique Bug ID for each issue (e.g., BUG-001, BUG-002, ...).
2. Select the journey where the bug was found.
3. Describe what should have happened vs. what actually happened.
4. Update the Status as the bug is triaged and resolved.

## Status Definitions

| Status | Meaning |
|---|---|
| Open | Newly reported, not yet triaged |
| Confirmed | Bug reproduced and confirmed |
| In Progress | Fix being worked on |
| Fixed | Fix implemented, pending verification |
| Verified | Fix confirmed working |
| Won't Fix | Intentionally not addressed (with reason) |
| Duplicate | Already reported under another Bug ID |
| Blocked | Cannot reproduce or depends on another fix |
